# CRUDAPI

A C# API project that demonstrates common CRUD (Create, Read, Update, Delete) operations.

## Features

- RESTful API endpoints
- Create, retrieve, update, and delete operations
- C# implementation
- Centralized API structure for CRUD functionality

## Technology

- **Language:** C#
- **Project type:** Web API
